# Haroma Waffles

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Run locally

1. Open this folder in Visual Studio Code.
2. Open `index.html` with the Live Server extension, or open the file directly in a browser.

## Project files

- `index.html` — page content
- `styles.css` — responsive layout and styling
- `script.js` — welcome intro, rotating product images, and quantity/cart estimate
- `assets/` — logo and menu photos

The cart calculates quantities and an estimated total in the browser. It does not submit orders to a service.
